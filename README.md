# InfiniteStrike

一个用 **Xcode + SwiftUI + SpriteKit** 写的 2D 俯视无限地图射击游戏。

## 运行方法（在你的 Mac 上）

1. 把整个 `InfiniteStrike` 文件夹拷到 Mac 上任意位置。
2. 双击 `InfiniteStrike/InfiniteStrike.xcodeproj` 用 Xcode 打开（需 Xcode 15 及以上，macOS 13+）。
3. 顶部目标选择为 **My Mac**（Apple Silicon 原生，已在工程中锁定 `ARCHS=arm64`）。
4. 按 **⌘R** 编译运行。
   - 首次运行若提示签名，选 Xcode 菜单 **Product → Run** 即可，工程已设为“本地签名（Sign to Run Locally）”，无需开发者账号。

## 操作

| 按键 | 功能 |
|---|---|
| WASD | 移动 |
| Shift | 疾跑 |
| 鼠标 | 瞄准 |
| 左键 | 射击（按住连发） |
| R | 换弹 |
| 1–6 | 切换武器 |
| Esc | 暂停 / 继续 |
